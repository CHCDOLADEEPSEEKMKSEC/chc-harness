# Contributing

Small project, blunt rules.

- One change per pull request. Say what it fixes and how you know it fixed it.
- Before pushing: `python3 -m py_compile app.py` and `bash -n install.sh`.
- Bug reports: distro, Python version, exact command, traceback.
- No new dependency unless the standard library genuinely cannot do it.
- No telemetry, no analytics, no phone-home. Ever.

Security issues: do **not** open a public issue — mail the address on
<https://ai.94-237-56-140.sslip.io/security>.
